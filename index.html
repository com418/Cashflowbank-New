Questions, answered.

Know what this prototype does before you begin.

Is Cashflowbank a real bank?

No. This version is a website prototype. It is not a licensed financial institution and does not hold or move real money.

Can I use the admin panel to manage these records?

Yes, the separate admin.html can manage sample records in the same browser on the same device. It is not secure enough for real customers or public deployment.

Will my account work on another phone?

This front-end version uses browser storage, so records are local to that browser. A secure backend is required for shared accounts and cross-device access.

Which countries can I choose?

The registration list intentionally excludes African countries as requested.
